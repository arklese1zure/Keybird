# Index

## Hooks
Keybird's hook system lets addon authors insert code at various locations:
- Specific times during the script's execution.
- Add content to specific elements of the GUI, like menus, and tabs.
- Add custom actions to GUI elements.

## Helper functions
- These helper functions let you add elements without needing to remember a lot of parameters.
- Unlike the Hook (`Plugin_*`) functions, these won't be called automatically during runtime.
